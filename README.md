# 🛒 Zepto SQL Data Analysis

A SQL-based data analysis project exploring **Zepto product, pricing, discount, and inventory data** using PostgreSQL.

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- GitHub

## 🔍 Analysis Covered

- Data exploration & cleaning
- Product and category analysis
- Discount and pricing analysis
- Stock availability analysis
- Revenue estimation
- Price-per-gram analysis
- Inventory weight analysis

## 📊 Key Insights

The analysis answers business questions such as:

- Which products have the highest discounts?
- Which categories generate the highest estimated revenue?
- Which products are out of stock despite having a high MRP?
- Which products offer the best value based on price per gram?
- Which categories have the highest average discounts?
